## Comandos útiles
Para consultar la configuración de red:
```bash
ip addr
```

Este comando permite consultar las direcciones IP y las interfaces de red del equipo.


Para comprobar la conectividad:
```bash
ping 8.8.8.8
```
Este comando permite comprobar si existe conexión con otra dirección IP.

## Gestión de usuarios

Para consultar el usuario actual:

```bash
whoami
```

```bash
git status
```

## Conclusión

Esta guía recoge algunos comandos básicos de Linux para consultar la configuración de red, comprobar la conectividad y gestionar usuarios.

Conocer estos comandos facilita la administración y el mantenimiento de un sistema Linux.
